# RED<span class="y">code</span> docs

REDcode is a Cyberpunk 2077 modding IDE built on VS Code. These pages track its setup and, as the extensions appear, how to use them.

| Document | What it covers |
|---|---|
| [Dev setup](dev-setup.md) | Every tool and step needed to build REDcode on a new machine |

The design document is not published yet. It will appear here with the first working extension.

## Roadmap status

| Phase | Status |
|---|---|
| C0 Decide | Done. See the REDbridge docs for the WolvenKit build findings |
| C1 Bridge MVP | Done. The extension (then `redcode-core`, now `redcode`) opens a game file as JSON through REDbridge |
| C2 Browse | Done. Project view over `.cpmodproj`, Game Assets tree, add to project, extract, open as JSON. Verified by hand on 2026-10-11: a project made in REDcode opens and packs in WolvenKit, and Extract To matches WolvenKit's output |
| C3 Edit | In progress. Done and verified by hand on 2026-10-11: Save JSON to Project (edits under `components` stick, `compiledData` is regenerated by WolvenKit, numbers are 32-bit floats), the texture viewer, TweakXL language support. The CR2W editor is designed ([design page](design/cr2w-editor.html)); E1 (bridge document sessions, REDbridge 0.5.0) and E2 (the editor: tree, property grid, undo and redo, backup and replay) are done and verified by hand on 2026-10-12. E3 (search across the file, the localization table view, `.json` and `.csv` CR2W files detected by their magic) is built and awaits the owner's hand test. Next: E4, the atlas view |
| C4 to C7 | Not started |
